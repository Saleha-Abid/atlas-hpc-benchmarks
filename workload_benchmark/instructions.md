# Instructions to Collect Workload Benchmark Results

This guide provides instructions to run, reproduce, and visualize deep learning training benchmarks across the Atlas storage tiers: persistent network-replicated DRBD storage (`/data`) versus localized high-speed NVMe storage (`/scratch`)[cite: 1].

---

## 1. Experimental Overview

The benchmark assesses single-GPU training throughput, epoch makespan ($T_{\text{epoch}}$), and I/O data-loading wait overhead ($\delta_{\text{I/O}}$) across three representative model architectures:
* **ResNet-50:** Emulates convolutional computer vision pipelines on $224 \times 224$ synthetic image payloads (Batch Size: 64).
* **Vision Transformer (ViT-B/16):** Evaluates attention-based visual backbones with $16 \times 16$ patch tokens (Batch Size: 32)[cite: 1, 2].
* **BERT-Base:** Evaluates sequence classification NLP models with 128-token sequences coupled with frequent intermediate checkpoint serialization every 25 steps to stress metadata and small-file write operations (Batch Size: 32)[cite: 1, 2].

---

## 2. Directory Layout

```text
workload_benchmark/
├── benchmark_test.py    
├── benchmark_test.sh    
├── chart.py            
├── chart.sh             
└── instructions.md      
```

### Step 1
Run `benchmark_test.py` on Atlas HPC using `benchmark_test.sh`.

```bash
sbatch benchmark_test.sh
```

### Step 2
The results will be compiled in a log file. Collect results from there and edit the `chart.py` file accordingly.

### Step 3
Run `chart.py` on Atlas HPC using `chart.sh`. A plot will be generated by the name of `dl_benchmark_comparison.png`.

```bash
sbatch chart.sh
```
